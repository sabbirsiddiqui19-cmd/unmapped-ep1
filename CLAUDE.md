# The Unmapped Page

Faceless YouTube channel of map-led history documentaries for a US and UK audience. This repo holds the production workflow and each episode's research and upload files.

- Workflow and setup: `.claude/skills/README.md`
- Pick and research a topic: `/topic-research`
- Build an upload kit for a finished episode: the `upload-kit` skill
- Owner-facing notes are in Bengali; anything viewers see is in English.

Rules:

- `PUBLISH = NO`. Never upload, publish or change YouTube settings.
- Never commit `.env`, API keys, rendered video or audio. Large outputs go to Google Drive.
- This repository is public. Keep personal data out of it.
